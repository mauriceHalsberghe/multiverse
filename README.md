# Multiverse - Tatooine

## About the Project

An interactive 3D experience built around **Tatooine**. Explore the environment, discover points of interest (POIs), interact with objects and experience a physics-based minigame.

## Features

- Interactive 3D environment created with Blender.
- Multiple points of interest with HTML information panels.
- Smooth camera animations using GSAP.
- Physics-based minigame powered by Rapier.
- Ambient audio and interactive sound effects.
- [Other unique features or easter eggs.]

## Technologies

- React
